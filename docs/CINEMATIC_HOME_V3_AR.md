# الإصدار v3.0 — مقدمة سينمائية لموقع Oman Earth Intelligence

## ما تم تنفيذه

- صفحة افتتاحية حقيقية داخل React؛ ليست صورة ثابتة وليست فيديو أو شاشة تحميل مفروضة.
- كرة أرضية Three.js باستخدام NASA Blue Marble محليًا، وتدوير تلقائي بطيء، والسحب بلوحة المؤشر أو مفاتيح الأسهم.
- محاولة عرض حدود سلطنة عُمان من خدمة NCSI الموجودة داخل المشروع؛ إذا فشل المصدر تُعرض النقطة الجغرافية دون اختراع حدود.
- صورة أولية سريعة مشتقة من نفس خامة NASA تظهر قبل اكتمال تحميل WebGL، مع احتياط بصري للأجهزة الضعيفة.
- زر «Start Exploring» يبدأ حركة تقريب نحو عُمان لمدة 440 ملي ثانية تقريبًا ثم يفتح المستكشف؛ يمكن الانتقال حتى لو لم يكتمل تحميل الكرة ثلاثية الأبعاد.
- الانتقال التلقائي بين الصفحات يعتمد على View Transitions عند توفرها، وينفذ بدون حركة عند اختيار Reduced Motion.
- خرائط MapLibre تُحمّل عند الدخول إلى لوحة التحليل وليس عند عرض المقدمة أول مرة، مما يقلل عبء JavaScript الأولي.
- بطاقات الأزرار والتنقل تفتح صفحات المشروع الحقيقية ولا توجد روابط وهمية.

## النشر على Windows

افتح مجلد المشروع الذي يحتوي على package.json ونفذ:

```powershell
npm.cmd install
npm.cmd test
npm.cmd run build
npx.cmd wrangler deploy
```

مهم: لا تعتمد نجاح النشر فقط للحكم على دقة الخريطة. اختبر الحدود من NCSI، وعرض الهاتف، وتحقق من قيم NASA على نحو مستقل. لا تعني هذه المقدمة أن الموقع يقدم طقسًا حيًا.

## ملاحظات الاختبار

الاختبارات المحلية التي لا تتطلب الاعتماديات نجحت. تعذر إجراء build لـVite داخل بيئة إعداد الحزمة بسبب عدم إمكانية الاتصال بـnpm registry (EAI_AGAIN). شغّل الأمر npm.cmd run build على جهاز Windows قبل النشر؛ لا يمكنني تأكيد نجاح البناء النهائي في هذه البيئة.
