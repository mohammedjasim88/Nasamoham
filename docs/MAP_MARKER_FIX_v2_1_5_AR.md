# Oman Earth Intelligence v2.1.5 — إصلاح الخريطة

## ما الذي تغير؟

1. **المصدر لم يتغير:** خرائط الأساس OpenFreeMap المبنية على OpenStreetMap، والحدود الإدارية NCSI كما في v2.1.4. لا توجد حدود مرسومة يدويًا ولا بيانات ناسا مُختلقة.
2. **أصل المشكلة:** العنصر `.map-point` كان يأخذ `position:relative` رغم أن MapLibre يحدد موضعه باستخدام حساب الإحداثيات و`transform: translate(...)`. التعديل الآن يجبر *عنصر العلامة فقط* على `position:absolute; top:0; left:0`، ويترك التحويل تحت إدارة MapLibre.
3. **قراءة أوضح:** عند عرض السلطنة كاملة، تُخفى أسماء المدن غير المختارة لمنع ازدحام الملصقات، مع استمرار ظهور نقاطها. تظهر الأسماء عند التقريب.
4. **الهاتف:** منع دوران الخريطة عرضيًا أثناء اللمس، مع الحفاظ على التحريك والتكبير.
5. **بيانات NASA:** لم تُغيَّر ملفات المصادر أو الاستيراد أو الإحصاء أو طلبات NASA.

## النشر من Windows PowerShell داخل مجلد المشروع

```powershell
npm.cmd install
npm.cmd test
npm.cmd run build
npx.cmd wrangler deploy
```

تأكد من ظهور اسم `oman-earth-intelligence-practice` عند النشر؛ ثم افتح الموقع واضغط `Ctrl+F5` أو أعد تحميله في الهاتف.

## ما الذي يحتاج تأكيدًا بعد النشر؟

- خصب على مسندم، وصحار على الساحل الشمالي، والبريمي غرب صحار، وصلالة جنوب ظفار.
- حدود المحافظات الـ11 تظهر من خدمة NCSI عند نجاح الاتصال؛ عدد الطبقات ليس إثباتًا للمطابقة القانونية الدقيقة.
- على هاتف حقيقي: تحريك الخريطة، التقريب، وتبديل وضع فاتح/داكن.
- ملصقات المدن لا تغطي الخريطة عند العرض الكامل وتظهر عند التقريب.

فحص بناء ناجح أو اختبار صيغ لا يثبت وحده صحة عرض كل الأجهزة أو مزودي الخرائط في كل وقت.
